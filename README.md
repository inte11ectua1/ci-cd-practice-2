# Учебный калькулятор

Практическая работа 2 по CI/CD.

## Возможности

- add(a, b) — сложение двух чисел.
- multiply(a, b) — умножение двух чисел.

## Требования

Python 3.12. Сторонние библиотеки не требуются.

## Запуск тестов

`python3 -m unittest discover -v`

## Генерация документации

`python3 -m pydoc -w calculator`

Команда создаёт файл calculator.html.

Документация также автоматически формируется в GitHub Actions.
Скачать её можно в разделе Artifacts соответствующего запуска:
архив project-docs, файл calculator.html.
